# PassBee
A simple and organized password manager built with Rust.

## Features
- Password encryption with AES-GCM
- Encrypted password storage with .json
- Ability to create multiple users
- Secure random password and passphrase generator

## Planned Features
- Cloud Sync
- API to check for leaked passwords
- More app customization
- Multiple vaults per user

## Installation
### Prerequisites
- Rust installed ([rustup.rs](https://rustup.rs))
